# PulseChat

Telegram-inspired messaging application built with React Native, Expo Router, TypeScript and Supabase.

## Current milestone
Phase 5 — editable authenticated user profiles.

Implemented so far:
- Android Expo development build
- navigation skeleton
- reusable messenger design system
- Supabase email/password authentication
- persisted sessions and protected routes
- RLS-backed profile records
- display name, username and bio editing
- avatar crop/compression/upload/removal with Storage RLS

See `PHASE5_README.txt` for the exact Phase 5 setup/test sequence and `docs/PROJECT_STATE.md` for project state.
